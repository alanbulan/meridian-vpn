## 结论先行

不能说“UniVPN 功能已全部到位”。Meridian 当前是原生 MyGo 界面 + Linux NetworkManager/OpenConnect AnyConnect 子集；界面基础连接管理可用，但 UniVPN 的 SSLVPN 协议互通未证实，L2TP/IPsec、代理、证书/MFA、多网关、配置迁移、自动登录/重连、错误报告、密码修改等仍有明确缺口。即使补齐表单，也不能算协议或端到端完成。

## 可立即实施 vs 需协议/授权

1. 不依赖真实网关即可实现并测试：描述、严格版本化导入/导出（自有格式且排除秘密）、能力清单、搜索/编辑/删除完善、真实接口IP/计数、脱敏日志导出、语言跟随系统、帮助/关于；代理/证书引用/多网关只在明确后端支持时启用。
2. 需要实际后端契约/测试才能算完成：HTTP(S)/SOCKS代理认证、证书及挑战/MFA、分流/DNS恢复、可取消重连/切换、L2TP/IPsec。单有表单不算。
3. 不可由通用AnyConnect冒充：联软/Huawei SSLVPN认证/QUIC/国密、企业网关升级/改密、主机合规检查、自动发现链路备份地址。
4. 需要额外安全决策：记住密码/自动登录的密钥环与授权；系统自启动；浏览器PAC变更；系统依赖安装。此审计未执行这些变更。
5. 最后仍需真实Linux环境+已授权测试网关，验收成功连接、认证挑战、内网资源、DNS/路由、主动断开、异常恢复、退出清理。现阶段不能称Linux彻底打通。
