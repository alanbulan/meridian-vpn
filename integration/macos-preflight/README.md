# macOS 原生只读预检

这套工具补上“只有假函数测试，没有实际调用 Apple API”的验证缺口。它不创建、启动、停止、修改或枚举系统 VPN 服务，不读取密码、共享密钥、账号或 Keychain 条目，也不会把预检通过当作 VPN 可用。

## 两种模式

- `abi`：验证真实 CoreFoundation 字符串类型、长度、ASCII/NUL 边界、64 位整数转换，以及 SystemConfiguration 只读配置引用。只读创建引用不等于创建系统服务。
- `service`：另对用户明确指定的现有 L2TP 服务执行 `InspectExistingService`。它读取允许列表中的配置和已有会话信息；服务原来断开就保持断开，原来已连接也不会接管或断开。原生配置字典可能在系统库内存中包含秘密字段，工具不提取这些字段，不声称从未接触含秘密的原生内存。

必须在 macOS 上运行。交叉编译、跳过的测试、部分结果和失败结果均不会记为成功。报告目录必须是新目录，父目录须已存在。

```sh
python3 integration/macos-preflight/run.py abi --go /绝对路径/go --reports ./macos-abi-evidence
python3 integration/macos-preflight/run.py service --service-id 明确选择的服务ID --go /绝对路径/go --reports ./macos-service-evidence
```

`service` 模式会拒绝缺失显式认证配置、状态变化或无法完整验证的服务；不会猜测系统默认值，也不会修改配置以让检查通过。错误不证明服务本身不可用。

## 隔离与证据

测试在独立子进程组运行。构建使用临时目录中的固定源码快照，其哈希与编译输入一致，不把构建期间变化的工作目录当作已验证源码。构建阶段最长等待 180 秒；原生测试使用 Go 的 10 秒测试超时，外层最长等待 15 秒，超时或 Ctrl+C 等中断时终止自己的未回收子进程组并再等待最多 5 秒确认退出。操作系统进程创建及无法中断的内核调用不能承诺硬实时上限；如果终止状态无法确认，仍记录失败。被终止的只是只读预检，不是持有活动 VPN 连接的工作进程，不能把这个方案直接移用于连接清理。

持久报告 `evidence.json` 仅保存平台、架构、工具链、测试二进制和构建源码快照的 SHA256、必需测试名称及结果。不保存服务 ID、网关、账号、凭据、原生字典或子进程日志。内存读取日志上限为 1 MiB；临时日志在检查后关闭。

底层 Go API 的 context 只在同步调用之间检查。外层进程边界避免把可能卡住的框架调用放到应用主进程或 Stop 锁中，但不是生产连接工作进程，更不保证系统网络清理。

## 离线测试

```sh
python3 -m unittest discover -s integration/macos-preflight -v
```

离线测试完全使用合成 JSON 和模拟子进程，不加载 Apple 框架、不创建套接字、不访问真实服务。当前 Linux 环境只能执行这些离线测试和 Darwin 交叉编译；真实 macOS ABI/服务预检须另行运行。

生产接入仍需明确的系统服务配置/凭据模式、配置和会话漂移检查、实际内核路由、有效 DNS/IPv6 策略、可归属的清理确认，以及签名/授权和隔离网关验收。L2TP 不能通过换成 NEVPNManager 的 IKEv2/IPsec 类型来保持协议兼容。
