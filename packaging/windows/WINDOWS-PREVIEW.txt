Meridian 0.1.0-alpha.1 Windows 实验预览

本包不是已经通过真实网关验收的完整 Windows VPN 产品。默认“Meridian”入口只启动普通界面，不自动启用实验后端。开始菜单中的“Meridian - Experimental existing Windows VPN”入口显式启用受限的已有 Windows VPN 连接模式（--enable-windows-borrowed）；选择该入口不代表你同意连接或更改网络。

受限模式只使用你明确指定的现有电话簿和 VPN 条目，并校验网关、用户名和域。它不创建、修改或删除系统 VPN 配置，不接收或保存预共享密钥。每次连接仍须单独明确同意网络变化、Windows 凭据缓存以及共享会话引用；应用不将密码写入个人配置；Windows 可能缓存凭据，无法确认清理时本次会话的数据可能继续保留。不要仅因启动界面就认为连接已经建立。

此模式不拥有系统 VPN 会话的独占控制权，不提供 kill switch，也不保证完整的路由或 DNS 防泄漏。无法确认清理结果时，程序可能保留待清理状态并阻止直接退出；重试清理只核验原来的会话引用。它不能替代真实网关、凭据缓存、路由、DNS、断连和恢复验收，不承诺 AnyConnect、UniVPN 或任意 L2TP/IPsec 网关都可用。Windows MFA 辅助程序未提供。

安装仅面向当前用户，不要求管理员权限，不安装驱动或服务，不修改网络、路由、防火墙、系统代理或开机启动。桌面快捷方式由你自行选择，仍使用默认普通模式。卸载保留个人配置，不自动删除其他 VPN 配置。请先完成连接清理，再卸载。

此版本未经代码签名。Windows 可能显示未知发布者提示；请核对发布来源和 SHA-256，不要关闭系统安全设置。

自动化安装测试仅验证安装文件、版本、两种空配置界面的可见窗口、正常关闭和卸载，不代表真实 VPN、生产环境安全或完整桌面交互验收。测试运行器使用管理员用户，当前用户安装模式通过不等于已经测试独立的非管理员账户。
