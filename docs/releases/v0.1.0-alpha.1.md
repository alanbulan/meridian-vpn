# Meridian 0.1.0-alpha.1 — Linux amd64

Unsigned, experimental Linux prerelease. This is a real GUI/foreground CLI build with an optional authentication-only MFA helper, not a production-readiness certification or an installer. Windows and macOS packages are not included in this release.

## Verify and run

SHA-256 for `meridian-linux-amd64.tar.gz`:

```
9247a8c826b7f8683ac4758e52fddb5df0e66e8eba3d115bdbe5501073c99d36
```

Check the archive checksum before extracting, then verify the package's internal `SHA256SUMS`. Checksums are not publisher signatures. Extract to a directory owned by you with trusted ancestors and no group/world-writable permissions, not `/tmp`. Keep the helper beside both binaries. Run `./meridian --version`, `./meridianctl version`, and `./meridianctl diagnostics --json`. Do not run the GUI as root. Diagnostics do not contact a gateway; missing dependencies cause exit code 1.

## External dependencies and limitations

The GUI requires GTK3/Pango/Fontconfig and MyGo desktop dependencies. VPN use needs a working desktop D-Bus/Polkit environment, NetworkManager and the distribution's VPN plugins. AnyConnect uses OpenConnect/NetworkManager-openconnect; L2TP requires NetworkManager-l2tp and its IPsec/PPP dependencies. The separate MFA helper requires compatible system libopenconnect 9.12+/API 5.9+ and dynamic dependencies. These components are not bundled or installed. The build-host helper handshake is not proof of target runtime ABI compatibility. Install dependencies through your distribution and check diagnostics on the target.

CI passed build/unit/vet, offline/race checks and localhost authentication/native fixtures. It did not validate a real corporate gateway, live tunnel, desktop interaction, internal reachability, route/DNS restoration, IPv6 leak protection, kill switch, reconnect or crash recovery. SSO/browser auth and Host Checker support are not implied. UniVPN's experimental native worker is not shipped. Real VPN use requires an authorized gateway and explicit network authorization. Disconnect normally rather than force-killing the program.
