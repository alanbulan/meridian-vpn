# Meridian 未验证开发预览版

本包仅完成编译与封装。本轮没有运行单元测试、数据竞争检查、软件启动、版本/帮助命令、认证握手、安装/卸载、界面交互或实际 VPN 验收。历史版本的验证结果不适用于本次新增代码。请先备份配置，不将本包当作生产环境完整 VPN 客户端。

Linux 包含 GUI、CLI 和仅认证的 MFA helper；依赖系统 NetworkManager、对应 VPN 插件及桌面授权环境。UniVPN 生产连接仍未实现，本包不安装或激活特权服务/原生数据 worker。安装包不会自动建立连接或启用开机自启。Linux .deb 可使用系统包管理器安装；请以普通用户运行 Meridian。

Windows 为未签名的当前用户安装包，不安装驱动或系统服务。既有 VPN 条目借用模式仍需显式启用和逐次授权，不能宣称具有独占会话所有权或完整路由/DNS泄漏保护；没有实际网关验证。

macOS 提供 ARM64 和 Intel 开发预览 DMG/PKG；没有 Developer ID 证书和公证，仅在本机构建时做 ad-hoc 封装签名。系统可能阻止安装或启动，不提供绕过 Gatekeeper/安全警告的操作。macOS 完整生产 VPN 能力与真实连接未完成验收，不安装特权后台服务。

全部平台均未证实真实企业网关互通、内网可达性、路由/DNS恢复、IPv6泄漏防护、断网保护和崩溃恢复。也不承诺厂商SSO、Host Checker、国密或QUIC兼容。具体功能以实际后端支持为准，尚未实现的能力不因生成安装包而视为完成。

安装包附带完整源码、第三方声明和构建清单。SHA-256仅用于文件完整性，不替代发布者签名。未选择或授予新的仓库许可证；第三方许可保持原样。
