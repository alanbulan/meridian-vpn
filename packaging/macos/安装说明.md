# Meridian macOS 开发预览安装包

此包可安装桌面应用及只读诊断工具，但 **macOS 实际 VPN 连接尚未完成，不是可用于企业接入的成品**。Linux 发布包的验收结论不能套用于 macOS。

- `.dmg` 包含 Meridian Preview.app；复制到自己的 Applications 目录即可保存应用。
- `.pkg` 默认以 `/Applications` 为目标位置；系统安装器可能根据既有应用位置处理升级。不安装后台服务、登录项、配置描述文件、Network Extension 或网络驱动；没有安装脚本。
- 应用采用临时本地签名，不具备 Developer ID 身份签名，也未公证。Gatekeeper 可能拒绝打开。不要关闭 Gatekeeper、删除隔离属性或绕过安全警告；需要常规分发时，应使用后续正式签名与公证版本。
- 删除应用即可移除本安装包的程序；应用运行后生成的个人配置不自动删除。

诊断工具位于应用的 `Contents/Helpers/meridian-macos-inspect`。不带参数只输出说明，不枚举服务。使用 `--service-id` 明确选择现有系统 L2TP 服务后，只读取有限配置与状态，不建立、断开、接管或修改连接，不读取账号/密码/PSK 到输出。Apple 配置字典本身可能包含凭据字段，不能声称没有访问含凭据的原生内存。同步系统 API 不能由 Go context 强制中断。

构建记录包括源码提交、架构和安装包 SHA256。macOS CI 执行框架只读 ABI 测试、包结构和签名完整性检查；不运行真实网关连接，也不把创建安装包、展开 pkg 或校验磁盘映像等同于完整安装/卸载验收。`live_vpn_verified=false`、`developer_id_signed=false`、`notarized=false` 明确保留。

正式交付仍需：用户明确授权的现有服务连接模式、配置/会话代际关联、路由/DNS/IPv6 验收、失败及退出清理、受授权隔离 macOS 网关测试、Developer ID Application（pkg 另需 Developer ID Installer）签名、公证和干净机器安装验收。
