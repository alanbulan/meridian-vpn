Meridian 0.1.0-alpha.1 Windows 实验预览

重要：这是图形界面、配置管理和命令行的安装验证版本，不是已经可用的 Windows VPN 产品。当前 Windows VPN 后端尚未完成，不能承诺连接 AnyConnect、L2TP/IPsec 或 UniVPN；不要将它用于实际网络访问。

安装仅面向当前用户，不要求管理员权限，不安装驱动或服务，不修改网络、路由、防火墙、系统代理或开机启动。桌面快捷方式由你自行选择。卸载保留个人配置，不自动删除其他 VPN 配置。

此版本未经代码签名。Windows 可能显示未知发布者提示；请核对发布来源和 SHA-256，不要关闭系统安全设置。

安装测试只验证文件、版本、启动窗口和卸载，不代表真实 VPN、生产环境安全、网络恢复或完整桌面交互验收。Windows MFA 辅助程序也未提供。
