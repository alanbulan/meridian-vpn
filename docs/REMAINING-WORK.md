# 仍需完成的工作与原因

本版交付的是可验证的Linux开发版本，不代表联软UniVPN全功能或任意企业网关兼容。本表区分“当前未实现”和“已有代码但未实网验证”，避免把所有缺口都推给缺少测试机器。

|能力|现状与具体后续|
|---|---|
|企业网关完整连接、内网资源、路由/DNS恢复|已有Linux AnyConnect与L2TP/IPsec/NM后端；AnyConnect历史认证实际运行，恢复新增能力与NM流程受控测试。需要具备TUN/NM权限的授权环境与已确认网关再做实网验收；当前不修改宿主网络|
|联软专有SSL/国密/QUIC、Huawei部署细节|实验性联软持续控制/数据TLS传输已恢复，9项本地模拟测试通过；不是AnyConnect同义词。broker已有凭据校验IPC、进程生命周期及路由/DNS控制器代码，但可信hook会话来源、后代进程隔离和独占网络命名空间租约仍缺失，真实网关、特权部署、TUN/路由DNS回滚仍未验收；原生MFA/证书、国密、QUIC、IPv6、Huawei适配仍未实现|
|L2TP/IPsec及PAP/CHAP/PSK/IKE/ESP等参数|已实现NetworkManager-l2tp后端、原生入口、参数映射、会话内秘密通道、接口验证和回滚；仍需真实发行版插件/IKE/PPP协商、授权取消及路由DNS恢复验收|
|PKCS#12、硬件令牌、USB-Key/PIN、国密证书|已接入PEM、PKCS#12容器与受限PKCS#11 URI，新增格式有受控测试；PKCS#12本地真实OpenConnect认证已通过，企业网关及硬件provider/PIN互通、国密证书和USB-Key仍未验收，未实现provider安装/枚举|
|厂商SSO、网页认证、Host Checker/终端合规、推送轮询|本版结构化MFA文本/密码/选择表单不等于这些流程。现有组件明确拒绝外部浏览器/SSO与脚本执行，需要分别实现授权与信任边界|
|自动重连/链路备份/优选探测|尚未完成，不能归因于“只有UI或没机器”。需区分瞬断与认证失败、限制重试/锁号风险，制定仅内存的秘密复用/过期策略，禁止未授权跨网关发送密码。现有手动多网关、安全切换和断线后一次性重新认证提醒不冒充自动功能|
|记住密码/自动登录|未实现；需要系统密钥环和明确保存授权。当前故意不以明文配置替代安全存储|
|系统/PAC代理、代理账号密码|未实现；当前NM插件参数路径可能暴露凭据或使用集成认证。需安全凭据通道和PAC执行边界，现有显式HTTP/SOCKS5不嵌入密码|
|开机自启/系统服务安装|已实现Linux用户级XDG启动项的明确确认、只启动应用、启停/安全校验及隔离目录测试；未实际修改宿主启动项或验收系统登录后自动启动。系统级服务安装未实现|
|TCP缓冲区自定义|现有NM插件没有对应的已验证直接设置路径，需协议/系统服务适配而非无效控件|
|网关修改密码/自动升级/专有配置INI|仅新增安全只读INI结构预览，尚无私有字段映射/导入；其他能力需要对应网关/API/格式版本及合法验证，不能以JSON导入或应用升级冒充|
|完整系统错误报告、抓包、core dump|当前仅脱敏白名单依赖报告和结构化日志。更广收集可能含账号/网络拓扑/秘密，需要范围选择与二次审阅|
|Linux CLI连接/断开|已实现Linux AnyConnect/L2TP前台connect、非终端stdin有界凭据输入、显式本次网络授权、Ctrl+C/SIGTERM及输出失败时自身会话清理；有假后端/私有管道回归测试。终端MFA、跨进程disconnect、后台服务及真实网关/路由DNS恢复仍未实现或未验收，不是原手册CLI协议全等替代|
|macOS/Windows实际VPN后端|已在原生runner通过单测、vet、GUI/CLI构建及CLI help/version启动（fa52b2a，详见VALIDATION.md）；这不等于VPN后端或GUI人工验收。平台权限、安全服务/NetworkExtension、签名与真实隧道仍需独立实现验收|

完整来源页码与每个字段的模型、消费方和测试见 `REFERENCE-COVERAGE.md` 及 `reference/UNIVPN-FEATURE-AUDIT.md`。
