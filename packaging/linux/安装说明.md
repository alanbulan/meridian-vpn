# Meridian Linux 安装说明

这是适用于 Debian 13 / Ubuntu 24.04 的 amd64 `.deb` 安装包。其他发行版、版本和架构尚未验收。它包含图形界面、命令行和认证辅助程序，可在系统应用菜单中打开，无需手动解压。

1. 下载 `.deb` 与 `SHA256SUMS-deb`，核对校验值。安装命令中的文件名必须与实际下载文件一致；GitHub 可能将文件名中的 `~` 转为 `.`。校验值不是数字签名，本版未经代码签名。
2. 双击 `.deb`，使用系统软件安装器安装。某些桌面没有本地包图形安装器，可在下载目录运行 `sudo apt install ./meridian_0.1.0~alpha.1-2_amd64.deb`。
3. 从应用菜单打开“Meridian VPN 客户端”。不要以 root 身份运行程序。

此候选安装包为修订版 `0.1.0~alpha.1-2`；不会替换已发布的 `-1` 文件。系统包管理器会安装声明的图形界面、认证运行库和 Noto CJK 字体依赖。中文界面需要字体回退，不能仅凭窗口可见就判断文字可读。安装包不会配置 VPN、启动连接、建立开机自启、添加系统服务或修改网络设置。

实际 VPN 连接还需要系统 NetworkManager、桌面 D-Bus/Polkit 授权环境及相应 VPN 插件。为避免安装程序自动启动或更改网络管理服务，这些列为建议组件，不会由本包强制安装。AnyConnect 需要 `network-manager-openconnect`；L2TP 需要 `network-manager-l2tp` 及其发行版 IPsec/PPP 组件。请由你或管理员确认后通过发行版官方软件包安装。运行 `meridianctl diagnostics --json` 可检查环境，检查不会连接网关，缺少依赖时返回状态码 1。

卸载：在系统软件管理器中卸载 Meridian，或运行 `sudo apt remove meridian`。卸载不会删除你的个人配置或凭据，也不会删除其他 VPN 配置。先正常断开连接、退出程序再卸载。包管理器不会强制终止正在运行的客户端。

这是 0.1.0-alpha.1 早期测试版，不是生产环境就绪承诺。安装验收不等于真实 VPN 验收。真实企业网关、隧道、内网可达性、路由/DNS 恢复、IPv6 泄漏防护、断网保护、重连及崩溃恢复仍未验证。不承诺 SSO、浏览器认证、Host Checker 或 UniVPN 支持。

安装包重新封装已发布的原始二进制，二进制源码提交保持 `8e0aaa94034e44150345733dc482126a03469d9a`。安装脚本源码提交单独记录在 `installer-manifest.json`。安装说明和安装清单位于 `/usr/share/doc/meridian/`。可运行 `sha256sum -c /usr/share/doc/meridian/SHA256SUMS-installed` 校验实际安装路径下的文件。完整原始源码、依赖许可声明及原始构建清单保留在该目录的 `source-package/` 子目录，供追溯原始压缩包；其中原始 README 和校验文件针对压缩包布局，不适用于安装后的路径。不捆绑系统运行库、不选择或授予新的开源许可证，第三方许可仍适用。
