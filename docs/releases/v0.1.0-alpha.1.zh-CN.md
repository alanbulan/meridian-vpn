# Meridian 0.1.0-alpha.1：Linux amd64 测试版

这是未经代码签名的 Linux 早期测试版，包含可运行的图形界面、前台命令行客户端，以及仅负责认证的多因素认证（MFA）辅助程序。它不是安装器，也尚未完成生产环境验收。本次发布不包含 Windows 和 macOS 安装包。

## 校验与运行

`meridian-linux-amd64.tar.gz` 的 SHA-256：

```
9247a8c826b7f8683ac4758e52fddb5df0e66e8eba3d115bdbe5501073c99d36
```

解压前先核对压缩包校验值，解压后再检查包内的 `SHA256SUMS`。校验值不能替代发布者数字签名。请解压到由你拥有、上级目录可信、且不允许同组其他用户或所有用户写入的目录，不要放在 `/tmp`。认证辅助程序应与两个主程序放在同一目录。

可运行 `./meridian --version`、`./meridianctl version` 和 `./meridianctl diagnostics --json` 检查版本和依赖。不要以 root 身份运行图形界面。诊断命令不会连接网关；缺少依赖时会以状态码 1 退出。

## 外部依赖与使用限制

图形界面需要 GTK3、Pango、Fontconfig 及 MyGo 的桌面依赖。使用 VPN 需要正常工作的桌面 D-Bus/Polkit 授权环境、NetworkManager 及发行版提供的 VPN 插件。AnyConnect 使用 OpenConnect/NetworkManager-openconnect；L2TP 需要 NetworkManager-l2tp 及其 IPsec/PPP 依赖。

独立的 MFA 辅助程序需要兼容的系统 libopenconnect 9.12+/API 5.9+ 及动态库依赖。本压缩包不会附带或安装这些系统组件。构建机器上的辅助程序协议握手通过，并不证明目标机器的运行时 ABI 兼容。请通过发行版官方软件包安装依赖，并在目标机器上运行诊断。

持续集成已通过构建、单元测试、静态检查、离线测试、数据竞争检查，以及本机回环环境的认证与原生组件测试。但尚未验证真实企业网关、实际 VPN 隧道、桌面交互、内网可达性、路由/DNS 恢复、IPv6 泄漏防护、断网保护、自动重连或崩溃恢复。

本版本不承诺支持单点登录（SSO）、浏览器认证或 Host Checker，也不包含 UniVPN 的实验性原生工作进程。连接真实 VPN 必须使用获准访问的网关，并取得明确的网络操作授权。请正常断开连接，不要用强制结束程序代替断开。
